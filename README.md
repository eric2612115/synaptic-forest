# Synaptic Forest

## 項目概述

Synaptic Forest是一個革命性的智慧知識生態系統，基於動態演化的知識圖譜，能夠模擬自然生態系統和認知過程。系統能自主學習、自我反思、自我組織和演化，為用戶提供深度智能輔助和知識增強服務。

本前端項目旨在創建一個視覺震撼、交互流暢且直觀易用的界面，既能展示系統的強大功能，又能提供清晰的用戶體驗。特別適合投資者演示和專業用戶使用。

## 技術堆疊

- **核心框架**: React 20+, Next.js 15+
- **語言**: TypeScript 5.3+
- **狀態管理**: Redux Toolkit & RTK Query
- **WebSocket客戶端**: Socket.IO Client
- **UI/組件庫**: shadcn/ui + Tailwind CSS
- **3D渲染/可視化**: 
  - Three.js / React Three Fiber - 3D圖譜渲染
  - D3.js - 數據可視化
  - react-force-graph - 知識網絡可視化
- **動畫**: Framer Motion
- **表單處理**: React Hook Form + Zod
- **API客戶端**: Axios + SWR

## 功能需求

### 1. 用戶認證與管理

- **登入/註冊**: 實現基於JWT的認證流程
- **用戶配置**: 用戶可以設置偏好和系統選項
- **角色管理**: 支持不同類型用戶（管理員、普通用戶、訪客）

### 2. 知識森林視覺化

#### 2.1 動態知識圖譜

- **多維視圖**:
  - 3D知識生態系統視圖（默認）
  - 網絡視圖（著重關係）
  - 集群視圖（著重主題分組）
  - 時間視圖（著重演化過程）

- **節點表示**:
  - 形狀/大小反映節點類型和重要性
  - 顏色反映主題或活躍度
  - 透明度反映確定性或休眠狀態
  - 節點間連線反映關係類型和強度

- **交互功能**:
  - 放大/縮小/平移
  - 點擊節點顯示詳情
  - 拖動重新排列
  - 搜索和過濾
  - 重點路徑高亮

#### 2.2 知識演化視覺化

- **時間軸視圖**:
  - 滑動時間條控制
  - 關鍵時間點標記
  - 按時間播放知識演化動畫
  - 比較不同時間點的知識狀態

- **生命效果**:
  - 新知識"生長"效果
  - 知識連接"蔓延"效果
  - 抽象化"結晶"效果
  - 休眠知識"褪色"效果

#### 2.3 反思系統可視化

- **反思過程顯示**:
  - 視覺化反思四階段（觀察、評估、決策、執行）
  - 顯示當前反思焦點區域
  - 能量流動視覺化
  - 反思結果高亮

- **指標儀表板**:
  - 知識質量指標圖表
  - 連接性、深度、廣度等指標
  - 健康狀態視覺化

### 3. 對話與互動系統

#### 3.1 高級對話界面

- **聊天界面**:
  - 響應式設計，支持多設備
  - 富文本消息顯示
  - 代碼塊、表格等格式支持
  - 消息狀態指示器（發送中、已讀等）

- **思考過程顯示**:
  - 實時顯示AI思考步驟
  - 漸進式顯示生成內容
  - 思考模式可切換

- **知識關聯指示**:
  - 對話中提到的概念與知識圖譜的實時關聯
  - 視覺化顯示知識提取過程
  - 顯示新知識如何融入現有網絡

#### 3.2 語境感知功能

- **相關知識推薦**:
  - 基於當前對話顯示相關知識節點
  - 推薦可能有用但未提及的相關知識
  - 智能排序，優先顯示最相關內容

- **知識溯源**:
  - 從知識節點追溯到源對話
  - 從對話追溯到形成的知識

### 4. 系統狀態與控制

#### 4.1 能量系統界面

- **能量指示器**:
  - 視覺化顯示當前能量水平
  - 能量分配和消耗統計
  - 能量再生預測

- **能量控制**:
  - 調整不同操作的能量分配
  - 設置能量使用優先級
  - 觸發能量再生或保留

#### 4.2 系統健康狀態

- **健康儀表板**:
  - 系統整體健康指標
  - 潛在問題警報
  - 優化建議

- **維護控制**:
  - 手動觸發反思循環
  - 調整系統參數
  - 知識修剪控制

### 5. 專業模式與演示模式

#### 5.1 專業用戶界面

- **高級配置**:
  - 自定義視覺化參數
  - 設置系統行為偏好
  - 導出/導入知識

- **深度分析工具**:
  - 知識圖譜結構分析
  - 主題演化趨勢分析
  - 用戶-系統互動分析

#### 5.2 演示模式

- **引導式體驗**:
  - 預設的演示流程
  - 突出系統亮點
  - 控制台（隱藏式）供演示者控制

- **投資者視圖**:
  - 著重商業價值的界面
  - 關鍵指標和增長數據
  - 直觀展示系統能力

## 開發指南

### 1. 代碼規範

- 遵循TypeScript嚴格模式
- 使用ESLint和Prettier保持代碼質量
- 組件使用功能性組件和React Hooks
- 使用命名約定：PascalCase用於組件，camelCase用於函數和變量

### 2. 狀態管理

- 使用Redux管理全局狀態
- 使用SWR/React Query管理服務器狀態
- 使用Context API管理局部共享狀態
- 使用React Query和Socket.IO管理實時數據流

### 3. 性能考量

- 實現虛擬化列表和視圖
- 使用React.memo和useMemo優化渲染性能
- 實現3D視圖的LOD（細節層次）控制
- 大型數據集採用分頁或無限滾動

### 4. 測試策略

- 組件測試: Jest + React Testing Library
- E2E測試: Cypress
- 視覺回歸測試: Percy或Chromatic
- 性能基準測試: Lighthouse
